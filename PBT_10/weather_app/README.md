Weather App

Ứng dụng xem thời tiết hiện tại theo tên thành phố.

API đã dùng
wttr.in API

API lấy dữ liệu thời tiết miễn phí.

Endpoint:

https://wttr.in/{city}?format=j1

Ví dụ:

https://wttr.in/Hanoi?format=j1
