Infinite Scroll Gallery

Ứng dụng gallery ảnh với infinite scroll và lazy loading.

API đã dùng
JSONPlaceholder Photos API

Endpoint:

https://jsonplaceholder.typicode.com/photos

Ví dụ:

https://jsonplaceholder.typicode.com/photos?_page=1&_limit=20

Dùng để:

load danh sách ảnh
infinite scroll
lazy loading
Tính năng
Load 20 ảnh đầu tiên
Infinite scroll
Lazy loading images
Modal / lightbox xem ảnh lớn
Responsive grid:
Desktop: 4 cột
Tablet: 2 cột
Mobile: 1 cột
Kỹ thuật sử dụng
Fetch API
Async/Await
IntersectionObserver
Infinite Scroll
Lazy Loading
